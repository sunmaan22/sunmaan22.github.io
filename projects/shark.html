Camera-LiDAR Calibration Odometry Paho MQTT 실시간 대시보드

개요

아주대학교 SHARK 자율주행 동아리에서 진행한 프로젝트로, 차량의 위치·상태 데이터를 실시간으로 관제 시스템에 전달하고 지도·차트 형태로 시각화하는 텔레메트리 시스템을 구축했습니다.

핵심 구현

  • 센서 보정 — 카메라-라이다 좌표계를 일치시키는 캘리브레이션으로 위치·방향 추정 오도메트리 로직을 구현했습니다.
  • 경량 프로토콜 — Paho MQTT로 차량 제어 모듈과 관제 시스템 간 메시지 브로커 구조를 설계해 전송 지연을 최소화했습니다.
  • 실시간 시각화 — 위치·센서 데이터를 지도·차트로 매핑하는 대시보드를 구축해 판단 근거를 즉시 모니터링할 수 있도록 했습니다.
  • 확장성 고려 — 향후 딥러닝 기반 기능 확장을 염두에 두고 데이터 일관성을 유지하는 저장 파이프라인을 설계했습니다.

배운 점

차량 제어와 관제 시스템처럼 물리적으로 분리된 두 시스템을 경량 메시지 브로커로 느슨하게 결합하는 설계 감각을 익혔고, 이는 이후 산업 안전 모니터링 프로젝트(디지털 트윈)에서 MQTT 기반 대시보드 연동을 설계할 때 그대로 이어졌습니다.
