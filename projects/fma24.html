센서 융합 기반 복합 미션 주행 시스템

인지·판단·제어 모듈 개발 · HL Future Mobility Award 2024
Cam+LiDAR거리·크기 산출 클러스터링
FSM구간별 상태 머신 설계
PID/Stanley조향 파라미터 튜닝

Stack

OpenCV LiDAR Clustering ROS Git FSM PID / Stanley

개요

HL Future Mobility Award 2024에 출품한 자율주행 스케일카 프로젝트로, 신호등·교차로·돌발 장애물 등 트랙 구간별로 서로 다른 대응이 필요한 복합 미션 주행 시스템을 구현했습니다. 2025년 MORAI 시뮬레이터 기반 프로젝트(FMA 2025)의 전신 격으로, 여기서 다진 인지·계획·제어 구조를 다음 해 프로젝트에서 훨씬 정교하게 확장했습니다.

핵심 구현

  • 인지 고도화 — OpenCV 기반 차선 인식과 LiDAR 클러스터링으로 장애물 유무를 넘어 거리·크기까지 산출했습니다.
  • 상태 머신 — 신호등·교차로·돌발 장애물 등 트랙 구간별 대응 전략을 FSM으로 정의해 미션 대응력을 강화했습니다.
  • 제어 튜닝 — 차량 물리 특성을 반영한 PID/Stanley 제어로 조향각 급변을 방지하고 고속 주행 안정성을 확보했습니다.
  • 모듈 분리 개발 — ROS 환경에서 인지·판단·제어 모듈을 팀원별로 분리 개발하고 Git으로 통합·디버깅했습니다.
  • 구조 개선 — 토픽 통합과 FSM 동시화로, 이후 대회부터는 상황별 코드만 최소 수정해도 실행되도록 구조를 개선했습니다.

배운 점

여러 미션이 하나의 FSM 안에서 충돌 없이 전이되도록 설계하는 것이 생각보다 까다롭다는 것을 배웠고, 이때의 경험이 2025년 프로젝트에서 Lattice Planner + 정지구역 판단 + GPS 음영구간 FSM처럼 더 복잡한 상태 관리를 설계할 때 직접적인 밑거름이 되었습니다.
